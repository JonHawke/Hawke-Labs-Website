# Hawke Labs Website

The Hawke Labs website: a studio building apps and games. Built with React and Vite.

## Run locally
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Edit content
- Services, projects and your contact email are in `src/data.js`.
- The logo files are in `public/`: `logo-mark.svg` (icon), `logo-full.svg` (icon and wordmark) and `favicon.svg`.

## Deploy
Import the repo into Vercel or Netlify. Build command: `npm run build`. Output directory: `dist`.
